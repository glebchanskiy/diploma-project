\MakeUppercase{Интегрированная система управления потоками пользовательских обращений}: дипломный проект/ Г.~А. Левков. -- Минск : БГУИР, \the\year{}, -- п.з. -- ~\pageref*{LastPage}~с., чертежей (плакатов) -- 7 л. формата А1.

\vspace{4\parsep}

Целью дипломного проекта является разработка интеллектуальной системы для эффективного управления потоками пользовательских обращений. Система сокращает время обработки типовых запросов, снижает операционные затраты и повышает качество обслуживания, используя иерархическую базу знаний и управляемый поиск при помощи LLM.

Предметом исследования являются методы и алгоритмы интеллектуальной обработки информации, архитектурные подходы к построению масштабируемых систем, а также технологии интеграции LLM для помощи в навигации по структурированным базам знаний.

Разработанная система автоматизирует обработку запросов, предоставляя точные и объяснимые ответы на основе верифицированной базы знаний. Ключевая особенность – использование LLM не для генерации, а как интеллектуального навигатора, который интерпретирует запрос и управляет поиском в иерархической базе знаний. Система обеспечивает прозрачность процесса, показывая путь поиска ответа.

В первом разделе пояснительной записки проанализированы существующие подходы и решения. Выявлены их ограничения (негибкость, "черный ящик", риски LLM-генерации). Обоснована актуальность разработки собственной прозрачной и управляемой системы.

Во втором разделе описано проектирование системы: концептуальная модель с иерархической базой знаний и LLM-навигатором, варианты использования, модель данных, интеллектуальные механизмы (автоматическая обработка, прогнозирование эскалаций), архитектурные решения (модульность, масштабируемость, асинхронность).

В третьем разделе изложены этапы реализации. Описан технологический стек, структура кода. Детально рассмотрена реализация ядра: алгоритм поиска по графу знаний, управляемый LLM; интеграция LLM для интерпретации и навигации; формирование объяснений пути поиска. Описаны реализации адаптеров для Telegram-бота и web-приложения.
В четвертом разделе приведено технико-экономическое обоснование: расчет затрат и оценка экономического эффекта.

Результатом является программный прототип системы управления обращениями, включающий универсальное ядро для поиска по иерархической базе знаний, демонстрационный Telegram-бот и web-приложение. Ядро адаптируемо для различных предметных областей, требующих точной и объяснимой обработки информации.
